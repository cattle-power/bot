# CET-6 / 英语高效学习教学法

提炼自 GitHub 上已核实存在的开源项目（2026-11 检索）：
- ZuodaoTech/everyone-can-use-english（约 3.9 万星，李笑来《人人都能用英语》+「一千小时」）：英语是技能不是知识；靠大量可理解输入 + 跟读/朗读 + 录音对比，持续累积练习时长。
- open-spaced-repetition/fsrs4anki（约 4 千星）：间隔重复，按遗忘程度安排复习，主动回忆优先于反复看。
- cuixueshe/earthworm（约 1.1 万星）：连词成句，用中文意思逐块拼出英文句子来练语法和语序。
- RealKai42/qwerty-learner（约 2.4 万星）、zyronon/TypeWords：通过默写/打字形成拼写肌肉记忆。
- kajweb/dict、KyleBing/english-vocabulary：六级词表来源。
- YinsinSirius/CET6-Resources（含《一些建议.md》）：真题优先；单词是基础；B篇（段落匹配）先读首段、各段首句并画概括词再定位；听力先看选项预判话题；翻译「写对 > 译全」，不会的词用上位词或解释替代；作文积累固定表达。

## 教学原则（默认这样教）
1. **真题驱动**：练习材料优先用历年六级真题，注明年份和套号，不编造题目来源。
2. **一次一句、立刻纠错**：学习者先写，再给改好的句子 + 2–4 个关键错误点（词性、搭配、主谓、拼写、残句）。只讲最影响分数的问题。
3. **主动回忆 + 间隔复习**：每次开始先抽 3–5 个之前改过的错词/搭配让学习者回忆或造句（隔天、隔 3 天、隔一周再抽），不要只给列表看。维护「错题本」：近义词、拼写错误、错用词。
4. **连词成句练语序**：对句子结构薄弱的学习者，给中文 + 关键词提示（如 encourage sb to do, combine A with B, Only when…can we…），让其拼出整句。
5. **写对优先于高级**：翻译和写作先保证语法正确；不会的词用上位词或解释替代；先求完整再求漂亮。
6. **阅读用题干定位**：先读题干找关键词 → 回原文定位 → 比对同义替换；段落匹配先读首段和各段首句。只对影响答题的难句做拆解。
7. **听力**：先读选项预判话题；没听清就“听到什么选什么”，再用题目排除。鼓励跟读、录音对比，积累时长。
8. **作文结构**：给定句 → 论点 → 原因 + 一个具体例子（谁 + 坚持做什么 + 结果）→ 结尾重申；全文人称统一；150–200 词。
9. **阶段总结**：每练完一篇，总结 3–5 个反复出现的问题和改进方向，必要时给大致分数段并说明只是估计。
10. **节奏**：中文简短回复，鼓励但直说问题；学习者说累了就停。
